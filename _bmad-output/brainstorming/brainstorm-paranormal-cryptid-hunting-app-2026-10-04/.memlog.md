- (technique) started First Principles Thinking
- (idea by coach) The phone is not a detector; it is a case file that writes itself - the device is the narrator, not the instrument.
- (idea by coach) Bedrock fact: users cannot verify any claim, so the only real deliverable is a story they believe they took part in.
- (idea by coach) Sensors are inherently noisy - treat that noise as CONTENT, not as an obstacle to filter out.
- (idea by coach) The product's true artifact is the Case Report; every tool exists only to generate material for it.
- (idea by coach) Change the core verb from DETECT to INVESTIGATE - detection implies proof, investigation implies process.
- (idea by coach) The scarce resource the app manages is UNCERTAINTY; the engine's job is to protect it, not to spend it.
- (idea by coach) If the user can predict when an event fires, the product is dead - predictability is the primary anti-metric.
- (idea by coach) A session is a FIELD TRIP, not a tool launch.
- (idea by coach) The phone is a controller for a haunted world-layer overlaying the real place, not a measuring instrument.
- (idea by coach) Seed every session from place + time + weather + sensor noise = a one-time, unrepeatable fingerprint.
- (idea by coach) Evidence is not data - it is a SOUVENIR of a moment.
- (idea by coach) The emotional deliverable is: I have a story no one can disprove.
- (idea by coach) A hunt is a PROMISE (something might be out there); the report is the RECEIPT.
- (idea by coach) Rebuild rule: never show a number a user could try to verify - all readouts stay qualitative.
- (idea by coach) The app must be good even when NOTHING happens; silence is a designed feature, not a gap.
- (idea by coach) The real loop is WONDER - MOVE - NOTICE - RECORD, not scan - find.
- (idea by coach) Position it as a paranormal field journal whose sensors are flavor, never proof.
- (idea by coach) The true competitors are boredom and the user's own skepticism.
- (idea by coach) If a moment cannot be screenshotted, it did not happen - sharing is first-class, not a bonus.

- (insight) The whole product collapses into three engines - a seeded Investigation Engine, an Evidence/Case system, and a Journal/Progression layer - everything else is data.
- (insight) Uncertainty is the product; judge every system by whether it protects or spends uncertainty.
- (insight) The Case Report is the true hero screen and the growth engine - build it first, then back-fit tools to feed it.
- (insight) Place + time seeding is the cheapest source of infinite variety and the strongest moat against generic detector apps.
- (insight) The four MVP creatures are really four ARCHETYPES (Observer, Stalker, Mimic, Ambusher) - future creatures are parameter sets, not code.
- (insight) Cut the Equipment tab - tools live inside hunts. Tabs should be Home / Investigate / Journal / Profile.
- (insight) Monetize the CONTENT (creatures, expeditions, case themes), never the moment of fear.
- (decision) Ship four creatures deep, not many shallow - each with a unique verb and a unique fail state.
- (decision) Build the report and share card before the tools.
- (decision) Use qualitative readouts everywhere; expose no verifiable numbers.
- (decision) The free first hunt must include a real encounter; place the paywall after the second case.
- (decision) Data-driven creature definitions with behavior archetypes; the engine never hardcodes a creature.
- (decision) Four tabs only: Home, Investigate, Field Journal, Profile.
