## Intent

**Problem:** Epic 1 now has a gated token set (`src/ui/theme/tokens.ts`, Story 1.2) and no component reads it. Every surface Epic 1 still owes — onboarding (1.6), Profile and the About notice (1.7), the four-tab shell (1.8) — and every document surface Epics 3 and 6 own (the Case Report, the evidence ledger, the Journal) draws the same six primitives: a hairline, an ink-stamped seal, a stat cell, a signature strip, a ledger row and a state chip. Left unbuilt, each surface invents its own hairline, seal and slot and the design language drifts from the tokens the sync test just gate-locked. The whole value of the epic ordering is that later stories *compose* these rather than improvise them.

**Approach:** Build the six document components as pure, token-reading React Native primitives under `src/ui/components/`, each typed so a percentage, a unit-bearing distance or a raw signal strength is *unrepresentable* rather than merely unwritten, and prove each acceptance criterion with `@testing-library/react-native` renders under jest-expo. Add `react-native-svg` for the `Seal`'s distorted ring. Add one small typography helper under `src/ui/theme/` because the tokens carry design units (letter-spacing in `em`, line-height as a ratio) that React Native does not accept.

## Boundaries & Constraints

**Always:** every colour, dimension, radius and duration a component renders comes from `src/ui/theme/tokens.ts` (AD-17's raw-value lint governs every non-test file under `src/ui/**`). A status is always also a word and colour only reinforces it (UX-DR25). The `Seal` resolves its filter as `filters[components.seal.distortion]`, never a second literal. The signature strip's cell count is read from the `slots` array it is given — never a constant — and its pulse period from `animations.ntPulse.durationMs`. Every component is a pure function of its props: no store, no fetching, no clock, no side effect. Types are explicit (`readonly` props, `null` not `undefined`, no `any`, no `as` outside mappers/validators); variant sets are discriminated unions with an exhaustive `switch` and `default: never` where a union is switched on. Server/UI text is uppercased by the component where the design says uppercase, not by the caller.

**Never:** No component accepts or renders a percentage, an axis, a degree, a unit-bearing number, a distance, a bearing in degrees, or a raw signal-strength value — and no prop exists that would let a caller smuggle one in (a formatter, a suffix, a unit, a range). No drop shadow, glow, coloured shadow, blur or backdrop-dim (there are no shadows; depth is one tone step plus a `rule` hairline, `DESIGN.md` Elevation & Depth). No capsule control and no fully-rounded document surface (`rounded.DEFAULT` on buttons/chips/cards; `rounded.full` is for the genuinely circular only). No light theme, no second palette, no runtime theming. No animation faster than the 5 s field breath except `ntPulse`. Do not modify `DESIGN.md`, `tokens.ts`'s values, or `token-sync.test.ts`. Do not build Story 1.4's components (`HoldButton`, `Sheet`, `TabBar`, `FieldView`, `GrainOverlay`, `EvidenceCard`) or Story 1.5's claims lint. Do not add a placeholder barrel export for anything not built here.

**Two defects found and fixed while finishing.**

1. `src/ui/components/__tests__/SignatureStrip.test.tsx` did not typecheck: the pulse assertion reduced `unknown[]` and `noUncheckedIndexedAccess` made the accumulator `number | undefined`. Fixed by mapping to `number` and annotating `reduce<number>(…)`, which keeps the assertion (the two halves must sum to the token period) rather than dropping it.

2. **Every `render()` threw `actImplementation is not a function`, with a green typecheck and lint.** Root cause found by a throwaway diagnostic test, since the error names neither React nor the environment: the shell exports **`NODE_ENV=production`**, so `require('react')` resolved `react.production.js` — and React 19 exports `act` *only* from the development build, which is exactly what `@testing-library/react-native` v14 renders through. Latent since Story 1.1, which never rendered a component. Fixed at the root in `jest.config.js` (`process.env.NODE_ENV = 'test'` before the config is exported) rather than in the `npm test` script, so a bare `npx jest` behaves the same in every shell and no POSIX-only shell syntax is introduced. Diagnostic test deleted.

**One platform limitation recorded for review, not hidden.** `react-native-svg@15.15.4` warns at render time that `FeTurbulence` and `FeDisplacementMap` are *not yet supported on native platforms* (the full unimplemented list includes both, plus `FeComponentTransfer`, `FeImage`, `FeMorphology`, `FeTile`). The `Seal` renders the token's complete five-step filter and two of the five (`FeColorMatrix`, `FeComposite`) are implemented natively — the `seal-filter` suite asserts both against the token, and the suite comment says so — but on device the turbulence-and-displacement half of the ink is a no-op, so the ring can read clean-edged even though the AC's "never renders clean-edged" is structurally declared. Rendering the token's own primitives is what AD-17 requires (the Seal and the later `REVISED` stamp share one definition); a native-capable substitute would be a design decision the spec does not settle, so it is recorded rather than invented.

**One deliberate deviation, documented in code.** `LedgerRow` draws its verdict and `NO CASE` chips with a local `LedgerChip` rather than the state `Chip`, because `Chip`'s label union is the closed five (`READY`, `INFERRED`, `UNCHARTED`, `INTERFERENCE`, `REVISED`) and a verdict is not one of them. The local chip reuses the same document geometry (`rule-strong` border, `rounded.DEFAULT`, `meta` label) and says why in its doc comment.

## Design Notes

**Why `react-native-svg` is added, and why it is not enough by itself.** The `Seal` is a ring carrying text on a path — the one shape plain React Native cannot draw. `tokens.ts` already holds the filter as data (`filters.ntInk.region` plus five steps), and AD-17 requires the Seal and the later `REVISED` stamp to share one definition, so the component declares *those* primitives rather than approximating the ink. **But the package implements only two of them.** `react-native-svg@15.15.4`'s `FeTurbulence` and `FeDisplacementMap` call `warnUnimplementedFilter()` and `return null`, so the token's three turbulence/displacement steps render nothing on device: a `<Circle>` would read clean-edged and the AC's "never renders clean-edged" would be met on paper and violated on screen. The ring is therefore drawn as a closed `Path` whose radius varies slightly and deterministically from `filters.ntInk.steps[0].seed`, and the token's filter is *still* declared on the group — so the impression reads hand-applied everywhere, the one-definition rule holds, and the day the platform gains the primitives the ink sharpens with no code change. SDK 57 bundles `react-native-svg@15.15.4`; `jest-expo`'s preset already transforms `react-native-*` packages, so no Jest config change is owed for resolution — only the `NODE_ENV` one the Code Map now names.

**The em/ratio conversion is the story's one non-obvious moving part.** `DESIGN.md` writes letter-spacing in `em` and line-height as a ratio because those are the design's units, and `tokens.ts` preserves them deliberately. React Native wants absolute points for both, so `textStyle` multiplies by the step's own `fontSize`. Doing it per component would be six chances to get it wrong and six raw-value lint hits; doing it once in `type.ts` keeps `typography` the single source.

**Two product rules are enforced structurally, not by review.** "No percentage, no unit" is enforced by `StatCell` taking a `number` for its value and a closed union for its label, and appending nothing to either — there is no formatter, suffix, unit or free-text prop to abuse. "The strip count is the case's, never a constant" is enforced by taking `slots` and rendering `slots.length` cells, so an archive wanting 8 passes 8 and a case wanting 7 or 9 passes that. Both are properties of the type, not of the current call sites. **The accessibility half is enforced the same way, by an explicit contract rather than by hope:** the meaning these components carry is carried by words, and a word that only the eye can read is not carried at all (AD-28), so each primitive names its word to assistive technology and the decorative hairline is hidden from it.
